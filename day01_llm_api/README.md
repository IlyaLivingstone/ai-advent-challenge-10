# День 1. Первый запрос к LLM через API

Минимальная CLI-программа на Python отправляет вопрос в облачную модель DeepSeek через REST API и выводит ответ в терминал. Сторонние зависимости не требуются.

## Требования

- Python 3.9 или новее;
- API key DeepSeek.

## Настройка

Задайте ключ в переменной окружения перед запуском:

```bash
export DEEPSEEK_API_KEY="ваш_api_key"
```

Ключ нельзя добавлять в исходный код или публиковать в репозитории.

## Запуск

Передайте вопрос аргументом:

```bash
python3 main.py "Объясни одним предложением, что такое LLM"
```

Либо запустите программу без аргументов и введите вопрос после приглашения:

```bash
python3 main.py
```

## Как это работает

`main.py` отправляет `POST`-запрос на `https://api.deepseek.com/chat/completions` с моделью `deepseek-flash`. Ответ извлекается из поля `choices[0].message.content` и выводится в консоль. Предусмотрены проверка API key, таймаут, обработка HTTP-ошибок и проверка структуры ответа.
