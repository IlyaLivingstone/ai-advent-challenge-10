# День 4. Температура

Самостоятельный Spring Boot-сервис для сравнения `temperature = 0`, `0.7` и `1.2` на двух типах запросов. Код LLM-клиента продублирован внутри модуля, зависимостей от других дней нет.

## Стек

- Java 21;
- Spring Boot 4.1.2;
- Maven 3.9+.

## Протокол

| Запрос | Тип | Проверка |
|---|---|---|
| Библиотека | один правильный ответ | `FINAL:` и точное число |
| Названия приложения | генерация | JSON-массив из 5 строк |

Каждая комбинация выполняется **10 раз**. Всего 60 запросов. Temperature передаётся в DeepSeek API, reasoning отключён, чтобы сравнивать именно температуру.

## API

- `GET /api/temperature/meta` — задачи и температуры;
- `POST /api/temperature/experiments` — запуск;
- `GET /api/temperature/experiments/{id}` — статус и отчёт;
- `GET /api/health` — health-check.

## Запуск

```bash
export DEEPSEEK_API_KEY="ваш_api_key"
mvn spring-boot:run
```

Сервис работает на `http://localhost:8082/`, интерфейс — на `/` и `/day4/`.

Тесты:

```bash
mvn test
```

## Результаты предыдущего прогона (5 повторов)

Таблица сохранена как история до увеличения числа прогонов до 10. После изменения конфигурации эксперимент не перезапускался.

### Точный ответ

Главная метрика — уникальные **семантические** ответы; `200` и `200 книг` считаются одним ответом.

| Температура | Уникальных | Верно | Формат |
|---|---:|---:|---:|
| 0 | 1/5 | 5/5 | 5/5 |
| 0.7 | 1/5 | 5/5 | 5/5 |
| 1.2 | 1/5 | 5/5 | 5/5 |

Температура не изменила ответ: во всех 15 прогонах одно и то же число.

### Генерация названий

| Температура | Уникальных | Diversity | Формат |
|---|---:|---:|---:|
| 0 | 3/5 | 0.51 | 5/5 |
| 0.7 | 5/5 | 0.78 | 5/5 |
| 1.2 | 5/5 | 0.87 | 5/5 |

При `0` уникальными были три набора из пяти. При `0.7` и `1.2` все пять наборов отличались.

### Выводы

- Главный эффект температуры виден на генерации: **3 → 5 → 5 уникальных ответов** из пяти.
- Для точной задачи температура не нужна: семантический ответ один и тот же при `0`, `0.7` и `1.2`.
- `temperature = 0` не гарантирует полностью одинаковый ответ: на генерации уже 3 набора из 5 различались.
- Правильность и формат — вторичные ограничители: 15/15 верных точных ответов и 15/15 валидных форматов.
- На этом наборе `1.2` дала максимальное разнообразие без поломки формата.
