# День 5. Версии моделей

Самостоятельный Spring Boot-сервис для сравнения трёх моделей на одинаковых задачах: точность, скорость, токены и стоимость.

## Модели

| Роль | Модель | Где | Цена за 1M токенов |
|---|---|---|---|
| Маленькая, бесплатная | `qwen2.5-coder:3b` | Ollama, локально | $0 |
| Средняя | `deepseek-flash` | DeepSeek API | $0.30 / $1.20 |
| Флагман | `k3.1-pro` | Kimi Coding API | $2.00 / $10.00 |

Цены DeepSeek и Kimi взяты из публичных тарифов на момент эксперимента. Для локальной Qwen стоимость API — ноль; время зависит от CPU/GPU.

## Протокол

- 7 задач из Дня 3, один и тот же промпт и evaluator;
- по одному замеру на задачу и модель: 21 запрос;
- перед замерами каждая модель прогревается;
- `max_tokens = 12 000`, `temperature = 0` для Qwen/DeepSeek; Kimi принимает только `temperature = 1`;
- таймауты: Qwen 180 с, DeepSeek 180 с, Kimi 180 с.

## API

- `GET /api/models/meta`
- `POST /api/models/experiments`
- `GET /api/models/experiments/{id}`
- `GET /api/health`

## Запуск

```bash
export DEEPSEEK_API_KEY="..."
export KIMI_API_KEY="..."
mvn spring-boot:run
```

Сервис работает на `http://localhost:8083/`.

Тесты:

```bash
mvn test
```

## Результаты

| Модель | Верно | Время | Токены | Стоимость |
|---|---:|---:|---:|---:|
| Qwen2.5 Coder 3B | 1/7 | 343,6 с | 3 433 | $0 |
| DeepSeek Flash | 7/7 | 83,4 с | 16 795 | $0.0195 |
| Kimi K3.1 Pro | 7/7 | 248,9 с | 19 629 | $0.1864 |

Qwen решила только задачу на вероятность. Остальные задачи — логика, двоичные строки, пути, уравнения, раскраски и рекуррентность — оказались для неё слишком сложными.

Kimi и DeepSeek решили всё. При этом Kimi:
- потратила на 17% больше токенов;
- была в 3 раза медленнее;
- стоила в 9,6 раза дороже DeepSeek.

### Вывод

Для этих задач **DeepSeek Flash — лучший баланс**: 7/7, самое низкое время среди облачных моделей и заметно меньшая цена. Kimi Pro не дала прироста точности на данном наборе, но стоила почти в 10 раз дороже.

Маленькой Qwen достаточно только для простых задач с коротким ответом; на сложных она ошибается, хотя формат ответа держит. Локальный запуск бесплатен по API, но на этой машине оказался самым медленным.
