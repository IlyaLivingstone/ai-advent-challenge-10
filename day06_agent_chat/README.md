# День 6. Первый агент

Самостоятельный Spring Boot-сервис: чат с агентом, который сам вызывает инструменты и использует их результаты в финальном ответе.

## Агент

Цикл:

```text
сообщение пользователя
  → LLM с описанием инструментов
  → tool_calls?
      → выполнить инструмент
      → вернуть результат модели
      → снова LLM
  → финальный ответ
```

В начале каждой сессии в историю добавляется системный промпт: он задаёт роль агента, обязывает использовать инструменты для времени/вычислений/валюты и запрещает выдумывать результаты. Системное сообщение входит в каждый API-запрос и видно в карточке `API · шаг N`.

Максимум 6 раундов, таймаут LLM 90 секунд, история сессии хранится в памяти.

## Инструменты

| Инструмент | Аргументы | Назначение |
|---|---|---|
| `current_time` | `timezone` | текущее время в часовом поясе |
| `calculate` | `expression` | безопасный арифметический калькулятор |
| `convert_currency` | `amount`, `from`, `to` | фиксированный курс RUB/USD/EUR |

Калькулятор реализован собственным рекурсивным парсером, без `eval`.

## API

```text
GET  /api/agent/meta
POST /api/agent/chat     # SSE: status, llm_request, llm_response, tool_call, tool_result, assistant, done, error
POST /api/agent/reset
GET  /api/health
```

Фронтенд получает `text/event-stream` через `fetch` и показывает вызовы инструментов прямо в ленте чата.

На каждом раунде в чате появляется раскрываемая карточка `API · шаг N`:
- **Что ушло в API** — полное тело запроса: модель, сообщения, история tool-вызовов и схемы инструментов;
- **Что вернулось из API** — сырой JSON ответа, включая `tool_calls` и usage.

## Запуск

```bash
export DEEPSEEK_API_KEY="..."
mvn spring-boot:run
```

Интерфейс: `http://localhost:8084/`.

Тесты:

```bash
mvn test
```

## Проверка трёх сценариев

1. **Без инструментов** — «Объясни, что такое AI-агент». Ответ за 1 раунд, `tool_call` нет.
2. **Один инструмент** — «Который час в Москве?». Вызван `current_time`, ответ за 2 раунда.
3. **Два инструмента подряд** — «Переведи 5000 рублей в доллары, затем увеличь результат на 10%»:
   - `convert_currency`: 5000 RUB → 54.05 USD;
   - `calculate`: 54.05 × 1.1 = 59.455;
   - финальный ответ за 3 раунда.

Тесты инструментов: 7, ошибок 0.
