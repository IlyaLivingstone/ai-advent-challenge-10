# День 7. Сохранение контекста

Самостоятельный Spring Boot-сервис: агент с инструментами, который сохраняет историю диалога в JSON и восстанавливает её после перезапуска.

## Что сохраняется

- вся история `messages`;
- системный промпт;
- сообщения пользователя и агента;
- `assistant.tool_calls`;
- сообщения `tool` с результатами инструментов.

Файл сессии:

```text
data/sessions/<session-id>.json
```

Запись атомарная: сначала `.tmp`, затем `ATOMIC_MOVE/REPLACE_EXISTING`. Id сессии валидируется, path traversal исключён.

## Восстановление

1. UI хранит `sessionId` в `localStorage`;
2. после перезапуска открывается тот же id;
3. `GET /api/agent/history?sessionId=...` возвращает сохранённые messages;
4. чат восстанавливает сообщения и карточки инструментов;
5. следующий запрос уходит в LLM вместе со всей прошлой историей.

API-трассы `llm_request/llm_response` показываются в live-режиме и **не сохраняются** в JSON. После перезапуска в истории восстанавливаются только сообщения, tool calls и результаты инструментов.

## Инструменты

- `current_time`;
- `calculate`;
- `convert_currency`.

## API

```text
GET  /api/agent/meta
GET  /api/agent/history?sessionId=...
POST /api/agent/chat
POST /api/agent/reset
GET  /api/health
```

## Перезапуск из UI

В левой панели есть кнопка **«Перезапустить сервис»**.

Она:
1. вызывает `POST /api/admin/restart`;
2. сервис запускает новую JVM с тем же jar и рабочим каталогом;
3. текущий процесс завершается;
4. UI опрашивает `/api/health` и перезагружает страницу;
5. история диалога остаётся в JSON и восстанавливается.

Для этой кнопки сервис должен быть запущен через `java -jar` (а не через IDE). Логи нового процесса пишутся в `restart.log`.

## Запуск

```bash
export DEEPSEEK_API_KEY="..."
mvn package
java -jar target/day07-context-persistence-0.0.1-SNAPSHOT.jar
```

Сервис: `http://localhost:8085/`.

Для разработки также можно запускать `mvn spring-boot:run`, но кнопка перезапуска рассчитана на jar-режим.

Тесты:

```bash
mvn test
```

## Проверка восстановления

Живой сценарий:

1. вопрос «Который час в Москве? Запомни это время»;
2. агент вызвал `current_time`, получил `19:44:17 MSK`;
3. JSON-файл сохранил 5 сообщений: `system`, `user`, `assistant`, `tool`, `assistant`;
4. сервис остановлен и запущен заново;
5. `history` вернул те же 5 сообщений;
6. продолжение диалога: «Какое время ты назвал в предыдущем ответе?»;
7. агент ответил `19:44:17 MSK, 11 ноября 2026`.

То есть контекст пережил перезапуск.
