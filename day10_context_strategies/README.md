# День 10. Сравнение стратегий контекста

Самостоятельный Spring Boot-сервис: агент с тремя стратегиями управления контекстом и ветвлением диалога.

## Стратегии

- **Summary** — summary старых сообщений + последние 8 (из Дня 9);
- **Sliding Window** — только последние 10 сообщений;
- **Sticky Facts** — key-value facts, обновляемые после каждого сообщения пользователя, + последние 10 сообщений.

Стратегия выбирается в правой панели и сохраняется в сессии.

## Ветвление

У сообщений в истории есть кнопка **«Ветка»**. Она создаёт новую сессию с сообщениями до выбранного чекпоинта; исходная сессия не меняется. Также доступна кнопка **«Ветка от последнего»** в тулбаре.

```text
POST /api/agent/sessions/{id}/branch
{ "messageIndex": 12 }
```

## Итоговый отчет

Кнопка **«Итоговый отчет по экспериментам»** в центре тулбара открывает таблицу:

- стратегия;
- сколько деталей сохранено из 5;
- потраченные токены;
- сложность поддержки;
- вывод, для каких сценариев подходит каждая стратегия.

Чтобы сравнение было полным, запусти сценарий для каждой из трёх стратегий.

## API

```text
GET  /api/agent/sessions
POST /api/agent/sessions
DELETE /api/agent/sessions/{id}
POST /api/agent/sessions/{id}/branch
GET  /api/agent/history?sessionId=...
POST /api/agent/chat
POST /api/agent/strategy
POST /api/agent/compression
POST /api/agent/scenario/next
GET  /api/health
```

## Запуск

```bash
export DEEPSEEK_API_KEY="..."
mvn package
java -jar target/day10-context-strategies-0.0.1-SNAPSHOT.jar
```

UI: `http://localhost:8088/`.

## Проверка

Сценарий Дня 9: 10 контекстных реплик с деталями и 5 контрольных вопросов. Для каждой стратегии запускается отдельная сессия; результат проверки и токены сохраняются в этой сессии.

Ветвление проверено через API: новая сессия получает копию сообщений до выбранного индекса и сохраняет стратегию исходной сессии.
