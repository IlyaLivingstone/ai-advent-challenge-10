# День 11. Модель памяти ассистента

Spring Boot-сервис с тремя явно разделёнными слоями памяти.

## Слои

| Слой | Что хранит | Куда попадает в промпт |
|---|---|---|
| Краткосрочная | все сообщения текущего диалога | весь текущий диалог |
| Рабочая | данные текущей задачи: ключ-значение | отдельный system-блок |
| Долговременная | профиль, решения, знания | отдельный system-блок, общий для всех сессий |

Долговременная память стартует с facts из Дня 10:

```text
project.name        = Колобок
project.deadline    = 15 декабря
project.budget      = 300 000 ₽
project.restriction = нельзя использовать внешние API
project.stack       = Java
```

## Хранение

- сессия: `data/sessions/<id>.json` — краткосрочные сообщения и рабочая память (рабочая память не переносится в новую сессию, но наследуется веткой от чекпоинта);
- долговременная память: `data/memory/long-term.json`;
- слои не смешиваются и очищаются независимо.

## Управление

В правой панели:

- видны все три слоя, количество токенов и записи;
- можно изменить правила/промпты для рабочей и долговременной памяти;
- после каждого сообщения модель раскладывает новые данные по слоям по этим правилам;
- можно вручную добавить запись в рабочую или долговременную память;
- удалить отдельную запись;
- включить/выключить слой;
- очистить слой.

## API

```text
GET    /api/agent/memory?sessionId=...
POST   /api/agent/memory/entry
DELETE /api/agent/memory/entry?sessionId=...&layer=...&key=...
POST   /api/agent/memory/clear
```

## Сценарий 5 сообщений

Кнопка в верхней части панели памяти создаёт новую сессию и прогоняет 5 контекстных реплик:

1. профиль пользователя и проект;
2. текущая задача, дедлайн и бюджет;
3. этап работы и следующий шаг;
4. долговременные ограничения и решение по стеку;
5. текущий артефакт и его дедлайн.

Реплики генерируются с учётом последнего ответа модели. После каждой срабатывает автоматическая раскладка по слоям памяти.

## Проверка

1. Задать вопрос по фактам Дня 10 — отвечает из долговременной памяти.
2. Добавить рабочую запись и задать вопрос по задаче.
3. Очистить долговременную память и повторить вопрос — агент перестаёт отвечать на факты проекта.
4. Очистить рабочую память — теряется контекст задачи.
5. Очистить краткосрочную — теряется текущий диалог.

Токены каждого слоя показываются в панели памяти.

## Запуск

```bash
export DEEPSEEK_API_KEY="..."
mvn package
java -jar target/day11-memory-layers-0.0.1-SNAPSHOT.jar
```

UI: `http://localhost:8089/`.
