# День 12. Персонализация ассистента

Spring Boot-сервис поверх модели памяти Дня 11: профиль пользователя добавляется в каждый запрос и пополняется из диалога.

## Профиль

Профиль — отдельная конфигурация над слоями памяти. Поля:

- имя;
- длина ответа;
- тон;
- как показывать код;
- ограничения.

Профиль добавляется отдельным system-блоком в каждый запрос независимо от того, включена ли долговременная память.

## Эксперименты

В правой панели две независимые конфигурации одной сессии:

- **Память** — слои памяти, правила слоёв, автоматическая раскладка;
- **Профиль** — выбор, создание и редактирование нескольких профилей, переключение активного профиля сессии. Профиль не зависит от слоёв памяти.

Обе панели работают с одной сессией. Отключение слоя памяти влияет и на профиль.

## Автообновление профиля

После сообщения пользователя сервис:

1. проверяет, не попросил ли пользователь изменить стиль/формат;
2. если да — обновляет поля активного профиля;
3. сохраняет профиль;
4. со следующего запроса применяет его.

## API

```text
GET  /api/agent/profiles
GET  /api/agent/profile?sessionId=...
POST /api/agent/profile
POST /api/agent/profile/save
GET  /api/agent/memory?sessionId=...
...
```

## Запуск

```bash
export DEEPSEEK_API_KEY="..."
mvn package
java -jar target/day12-personalization-0.0.1-SNAPSHOT.jar
```

UI: `http://localhost:8090/`.
